**ZeroTool** The Goodest Pentesting Tool

## ✨ Abilitys
- More Than **30 layer7 methods!**  (GET, POST, HEAD, Cloudflare Bypass, OVH Bypass, HTTP/2، Slowloris، XML‑RPC and more...)
- More Than **15 Layer4 method!** (UDP, TCP, SYN, ICMP, Valve, Teamspeak, FiveM, Minecraft andmore ...)
- Support Proxy (SOCKS5 / HTTP) 
- ** CheckHost ** ability without more cdn(s)

## 📥 How To Install?
1. Git Clone:
   ```bash
   git clone https://github.com/nullop1/zerotools
   cd zerotools
   ```
2. Install requirments or start.bat

```bash
pip install -r requirements.txt
```

Or double click on **start.bat** file

3.Run ( if you click on start.bat this is not important ) 

```bash
python zerotool.py
```
